# ChatGPT

ChatGPT adds MCP apps in its settings, not through a config file. Works on the ChatGPT website on paid plans.

1. On chatgpt.com open **Settings → Security and login** and turn on **Developer mode**. No such toggle? Go to step 2: some accounts already have it on.
2. Open **Plugins** (chatgpt.com/plugins) and press **+ → Create app → Create MCP App**.
3. Name: `Seedara`, URL: `https://seedara.ai/api/mcp`, authentication: **OAuth**. Create the app, sign in to Seedara and press **Allow**.
4. In a new chat press **+** and pick Seedara.

On Business and Enterprise an admin turns developer mode on first. The connection can take 5–10 minutes to appear.
